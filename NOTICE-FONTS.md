# Arabic fonts

The web build includes the following SIL Open Font License 1.1 fonts. Each bundled font is a
Unicode subset for Latin and Arabic scripts; its OFL license is retained in
[`apps/wordcraft-web/font-licenses/`](./apps/wordcraft-web/font-licenses/).

| Font | Copyright / authors | Source | License |
|---|---|---|---|
| Noto Naskh Arabic | Copyright 2022 The Noto Project Authors | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notonaskharabic) | [OFL 1.1](./apps/wordcraft-web/font-licenses/OFL-Noto-Naskh-Arabic.txt) |
| Amiri | Copyright 2010–2022 The Amiri Project Authors | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/amiri) | [OFL 1.1](./apps/wordcraft-web/font-licenses/OFL-Amiri.txt) |
| Cairo | Copyright 2009 The Cairo Project Authors | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/cairo) | [OFL 1.1](./apps/wordcraft-web/font-licenses/OFL-Cairo.txt) |

The font files are subsetted from the Google Fonts sources to Latin and Arabic Unicode ranges,
including the Arabic presentation forms used by OpenType shaping. The original family names and
copyright notices are preserved in the font metadata. The subsets are redistributed under the
same SIL Open Font License 1.1 terms as their respective originals.
